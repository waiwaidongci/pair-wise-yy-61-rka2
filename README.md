# pair-wise-yy-61 航空器定检工作包执行与放行审阅平台

支持工卡依赖、测量值容差校验、离线暂存、冲突提交提示、分阶段签字、版本差异和放行锁定。超差项目必须由授权人员处理后才能继续。

## 压力表链：测量 → 校准证 → 阶段签字 → 放行基线

机库共用液压压力表，校准证到期或撤掉后，旧压力测试和阶段签字仍随工作包保留，但链状态立即失效：

- **占用**：每张工卡占用一只有效压力表（校准证有效）；两名检验员同时提交同一只表时先到者占用，后到者收到占用冲突。
- **失效**：校准状态（到期 / 撤证）、量程或工卡版本一变，关联测量与阶段签字立即失效，原值保留待复测，放行基线回退。
- **复测**：由质量授权人确认后重新占用有效压力表复测，原测量值保留在链记录中。
-写入失败**：保留压力表占用与现场读数，按原请求（幂等键）恢复提交，不丢数据、不重复占用。

## 技术栈

React、Fluent UI、Redux Toolkit、React Router、RTK Query、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62061`。工卡草稿、压力表占用、测量链和审计操作保存在 `localStorage`。

```bash
npm run build
```
